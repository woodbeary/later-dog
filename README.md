## How it works

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="docs/assets/readme/how-it-works-dark.svg">
    <img src="docs/assets/readme/how-it-works-light.svg" width="484" alt="The Mac app and the iPhone app sign in once with your email and a code. They open your Cloud home, which keeps your dogs, chats, routines and memory and stays on when your Mac is closed. Each dog gets its own computer in the cloud. For AI, your dogs use the Claude, ChatGPT, Grok or Cursor plan you already have, or the free AI that comes with later.dog. Voice lets you talk to a dog and hear it answer.">
  </picture>
</p>

- **Sign in and go.** Type your email, enter the code, and your dogs are there. No keys, no setup.
- **One home for everything.** Your dogs, chats, routines and memory live in your Cloud home, which is always on. The
  Mac and the iPhone are two windows onto the same place.
- **Your Mac can help too.** While it is signed in, your dogs can use it as a second computer, for a file in Downloads
  or an app only you have. Without an account, the Mac runs your dogs on its own.
- **Talk out loud.** Talk to a dog and hear it answer.

## Download

- **Mac** (Apple silicon): [download the latest release](https://github.com/woodbeary/later-dog/releases/latest), drag
  later.dog to Applications and open it. It is signed, checked by Apple, and keeps itself up to date.
- **iPhone**: a free beta on [TestFlight](https://testflight.apple.com/join/UH46TVvC). Sign in with the same email.
- **Free to start.** The app is free and open source. Signing in gives you a Cloud home with an included allowance of
  computer time, AI and voice.

More at [later.dog](https://later.dog), and the [user guide](docs/laterdog/README.md) covers every screen.

## For developers

### Under the hood

<p align="center"><a href="docs/assets/architecture.svg"><img src="docs/assets/architecture.svg" width="900" alt="The Mac and the iPhone sign in at accounts.later.dog and open one Cloud home: a Worker, a Durable Object and a Container running the later.dog server. Your own Claude, ChatGPT, Grok or Cursor sign-ins run in that Container and talk straight to the provider. cloud.later.dog gives each dog its own computer, the included Kimi K2.6 with Grok backup through AI Gateway, and voice (Aura-2 or ElevenLabs). The signed-in Mac is a second computer."></a></p>

The Cloud home is a Cloudflare Worker with a Durable Object and a Container running the same later.dog server as the
desktop app; your Claude, ChatGPT, Grok or Cursor sign-ins run in that Container and talk straight to the provider.
`accounts.later.dog` handles email sign-in, and `cloud.later.dog` gives each dog its computer, the included AI (Kimi
K2.6 with Grok as backup, through AI Gateway) and voice (Aura-2, or ElevenLabs where it is switched on). Without an
account, the Mac runs dogs on its own and the app can offer the same allowance as a $10-a-month plan.

### Build from source

```sh
git clone https://github.com/woodbeary/later-dog.git && cd later-dog
pnpm install --frozen-lockfile        # Node 24 and pnpm 10.33
pnpm laterdog:package                 # unsigned local build → release/mac-arm64/later.dog.app
```

The released `later.dog-macOS-arm64.dmg` is signed and notarized and updates itself (**Restart to update**).

Coding agents: start with [`AGENTS.md`](AGENTS.md), the
[setup skill](skills/laterdog/setup-laterdog/SKILL.md) and [`llms.txt`](llms.txt).

### Project layout

| Path | What |
| --- | --- |
| `src/`, `server/`, `electron/` | The desktop app and the later.dog server (the same server runs in the Cloud home) |
| `deploy/laterdog/home/` | The Cloud home: Worker, Durable Object and Container |
| `deploy/laterdog/computers/` | `cloud.later.dog`: each dog's computer, the included AI, voice, trials and the plan |
| `cloudflare/control-plane/` | `accounts.later.dog`: email sign-in and accounts |
| `skills/laterdog/` | Canonical agent skills, exported by `pnpm laterdog:skills` |
| `docs/` | [User guide](docs/laterdog/README.md), [Cloud home contract](docs/cloud-pro.md), [verification](docs/verification/README.md) |
| `docs/assets/readme/` | The animations and diagram on this page, recorded from the [later.dog](https://later.dog) site's own scenes |
| `scripts/readme-media/` | Records those scenes from a local build of the site and encodes them (`render.mjs`), and draws the diagram (`how-it-works.mjs`) |

Current screenshots of the app live in [`docs/assets/screenshots/`](docs/assets/screenshots/README.md), taken from an
isolated fixture, never from someone's real data.

### What is proven, and what is not

CI runs lint, typecheck, the vitest suite, the Electron tests and the builds on every pull request.
[docs/verification/README.md](docs/verification/README.md) says how each change is proven on an isolated fixture, and
[docs/laterdog/verification.md](docs/laterdog/verification.md) keeps the live records. Fixture success never qualifies
a live provider.
